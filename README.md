# Challenge 6 — AutoEncoders & Representation Learning
## Group 4 · Universidad Distrital Francisco José de Caldas · Machine Learning

---

## Domain
**Education Systems** — Anomaly detection and representation learning on U.S. public schools
using NCES CCD SY 2022-23. Identifies anomalous schools relative to peers with similar
resource levels and visualizes latent school-characteristic manifolds.

## Dataset
Same as Challenge 5 — NCES CCD SY 2022-23.  
See `data/README_data.md` for download instructions.

## Quickstart

### 1. Download data
```bash
bash download_data.sh
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the notebook
```bash
jupyter lab notebooks/best_run.ipynb
```
Run all cells — takes ~15-20 minutes (AE + VAE training + t-SNE + UMAP).
