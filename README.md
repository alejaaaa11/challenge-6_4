## Domain
**Education Systems** — Anomaly detection and representation learning on ~95K U.S.
public schools. Identifies schools anomalous relative to peers with similar resource
levels and visualizes the latent school-characteristic manifold.

**Dataset:** NCES Common Core of Data (CCD) SY 2022-23 (same as Challenge 5)  
**Models:** AutoEncoder · Variational AutoEncoder · Isolation Forest

---

## How to Run

There are **two ways** to run this project. Choose the one that works for you.

---

### Option A — Docker (recommended, works on any machine)

**Requirements:** Docker Desktop installed → https://www.docker.com/products/docker-desktop

```bash
# 1. Clone the repo
git clone https://github.com/YOUR_USERNAME/challenge-6_4.git
cd challenge-6_4

# 2. Download the data files automatically
docker-compose run download

# 3. Start JupyterLab
docker-compose up notebook
```

**4.** Open your browser at: **http://localhost:8888**  
**5.** Navigate to `notebooks/` → double-click `best_run.ipynb`  
**6.** Click **Run → Run All Cells**

>  Training takes ~15-20 minutes (AE + VAE × 3 seeds + t-SNE + UMAP).  
> All results are saved to your local `figures/`, `results/`, and `models/` folders.

---

### Option B — GitHub Codespaces (no installation needed)

**Requirements:** A GitHub account and a browser.

**1.** Open the repo on GitHub → click **Code → Codespaces → Create codespace**

**2.** In the Codespace terminal:
```bash
# Download data
bash download_data.sh

# Install dependencies
pip install -r requirements.txt

# Start JupyterLab
jupyter lab
```

**3.** Copy the URL with the token and open it in your browser.

**4.** Navigate to `notebooks/` → open `best_run.ipynb` → **Run → Run All Cells**

> Data files are lost when the Codespace stops. Run `bash download_data.sh`
> again each time you reopen the Codespace.
